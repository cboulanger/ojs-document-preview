Adds a preview of submitted documents to the editorial workflow. A preview button appears before the file names of documents in a supported format: in the workflow's file lists, discussion attachments, the reviewer's files and the file selection dialogs. It opens the document in a dialog, with a link to download the original file: text documents as simple HTML (headings, paragraphs, emphasis, lists, tables, links, images, footnotes and endnotes), PDF files in the PDF.js viewer, images as they are.

  • Supported formats: DOCX, converted with mammoth.js (BSD 2-Clause, included in the plugin), and OpenDocument text (ODT, also the single-file FODT), converted by the plugin itself; PDF, shown with the viewer of OJS's own PDF.js PDF Viewer plugin (which must be installed, it need not be enabled); and images (PNG, JPEG, GIF, WebP, AVIF, BMP, SVG). Further formats can be added as renderers, also by other plugins.
  • Files are recognised by the extension of their name, or, if the name has none, by the media type OJS stored for them.
  • The file is loaded through OJS's own download link, so OJS's access rules apply unchanged: the preview never shows more than the user could download.
  • The conversion happens in the browser. Nothing is converted or stored on the server; no database tables, no settings.
  • Text documents and images are shown in a sandboxed frame: they can't run scripts, access OJS or load external resources. PDF files are shown in the PDF.js viewer, with JavaScript in the PDF turned off and links opening in a new tab.
  • Text documents get a simplified preview: page layout, headers, footers, comments, tracked changes and the file's metadata are not shown.
  • English and German.
