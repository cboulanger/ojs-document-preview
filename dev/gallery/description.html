Adds a preview of submitted documents to the editorial workflow. A preview button appears before the file names of documents in a supported format: in the workflow's file lists, discussion attachments, the reviewer's files and the file selection dialogs. It opens the document as simple HTML (headings, paragraphs, emphasis, lists, tables, links, images, footnotes and endnotes) in a dialog, with a link to download the original file.

  • Supported formats: DOCX, converted with mammoth.js (BSD 2-Clause, included in the plugin), and OpenDocument text (ODT, also the single-file FODT), converted by the plugin itself. Further formats can be added as renderers, also by other plugins.
  • Files are recognised by the extension of their name, or, if the name has none, by the media type OJS stored for them.
  • The file is loaded through OJS's own download link, so OJS's access rules apply unchanged: the preview never shows more than the user could download.
  • The conversion happens in the browser. Nothing is converted or stored on the server; no database tables, no settings.
  • The document is shown in a sandboxed frame: it can't run scripts, access OJS or load external resources.
  • Simplified preview: page layout, headers, footers, comments, tracked changes and the file's metadata are not shown.
  • English and German.
